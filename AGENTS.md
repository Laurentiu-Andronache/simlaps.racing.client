# Agent Instructions


## Python Environment
- Use the project virtual environment for Python commands:
- `venv-sim-laps-client/Scripts/python`
- Prefer:
  - `venv-sim-laps-client/Scripts/python -m pytest ...`
  - `venv-sim-laps-client/Scripts/python -m pip ...`

## Project Root
- Assume the working directory is the repository root: `sim-laps-client`.
